# lokatka-catalog

Katalog promocji bankowych dla aplikacji [Lokatka](https://lokatka.com).

- `catalog.json` — aktualne promocje (`offers`), zakończone edycje (`archive`), kursy walut NBP (`fx`) i data aktualizacji (`updated`).
- Plik jest aktualizowany automatycznie (poniedziałek i czwartek).
- Aplikacja pobiera go z `https://raw.githubusercontent.com/lokatka/lokatka-catalog/main/catalog.json`.

Dane mają charakter informacyjny — warunki promocji zawsze sprawdzaj w regulaminie banku.
